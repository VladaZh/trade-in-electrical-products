# Java-версия (ООП) системы оптовой торговли электротехнической продукцией

Та же программа, что и процедурная версия на Python: те же роли (клиент, отдел продаж, склад,
отдел доставки), те же операции, те же алгоритмы, те же входные данные и тот же вывод.
Данные хранятся в JSON-файле, база данных не используется; интерфейс — командная строка.

## Что нужно

- **JDK 17 или новее** (разработано и проверено на OpenJDK 21; исходники собираются с `--release 17`).
- **Сборка: `javac`**, без Maven и Gradle. Внешних библиотек нет (JSON-разбор написан в проекте),
  поэтому сборка не требует интернета.

## Сборка и запуск

Все команды выполняются из каталога `java/`! Чтобы перейти в эту папку из корня репозитория выполнить команду:
```Bash
cd java
```
Компиляция файлов
```Bash
mkdir -p out
javac -encoding UTF-8 --release 17 -d out $(find wholesale -name "*.java")
```

Сброс состояния перед запусками
```Bash
java -Dfile.encoding=UTF-8 -cp out wholesale.Main reset
```

Для запуска клиента, отдела продаж, склада и отдела доставки необходимо открыть разные консоли (всего 4). 

```bash
java -Dfile.encoding=UTF-8 -cp out wholesale.Main client
java -Dfile.encoding=UTF-8 -cp out wholesale.Main sales
java -Dfile.encoding=UTF-8 -cp out wholesale.Main warehouse
java -Dfile.encoding=UTF-8 -cp out wholesale.Main delivery
```

### Управление в консоли
Консоль показывает задачи, ожидающие решения роли. Введите **номер задачи**, чтобы выполнить
её; **Enter** обновляет список; **0** - выход. Дополнительные команды:

| Консоль | Команды                                                     |
|---|-------------------------------------------------------------|
| Клиент | `n` - новый заказ, `o` (английская o) - мои заказы подробно |
| Отдел продаж | `o` (английская o) - все заказы                             |
| Склад | `s` - остатки по партиям, `o` (английская o) - все заказы   |
| Отдел доставки | `o` (английская o) - все заказы                                           |

Отвечать на вопросы программы можно любым удобным способом (настроено в `ConsoleIO.java`):
private static final Set<String> YES_WORDS = Set.of("да", "д", "y", "yes");
private static final Set<String> NO_WORDS = Set.of("нет", "н", "n", "no");

## Пример работы: самовывоз (ввод и ожидаемый вывод)

### 1. Клиент

Выбрать клиента № 1 (ООО «ЭлектроМонтаж»).

**Ввод:**
```text
Выбор: n
Товар> 101 25
Товар> (пустая строка — конец списка)
Выберите способ (1-2): 1 (самовывоз)
Отправить заказ? (да/нет): да
```

**Ожидаемый вывод:**
```text
Сформирован заказ №1, сумма 237,500.00 руб.
Информация по заказу №1 передана в отдел продаж
```

### 2. Отдел продаж

Нажать Enter, выбрать задачу № 1. На вопрос «Данные заказа корректны?» ответить «да».

**Ожидаемый вывод:**
```text
Корректность данных подтверждена
Информация отправлена на склад отделом продаж
```

### 3. Склад

Нажать Enter, выбрать задачу № 1 «Сформировать партию» и ответить «да».

**Ожидаемый вывод:**
```text
Сформирована партия: 2 строк отбора
партия 1, ячейка A-01: Кабель ВВГнг 3x2.5 (бухта 100 м) - 20 шт.
партия 2, ячейка A-02: Кабель ВВГнг 3x2.5 (бухта 100 м) - 5 шт.
```

Затем выбрать задачу «Оформить документы на отгрузку» и ответить «да».

**Ожидаемый вывод:**
```text
Склад оформил документы на отгрузку №1
Заказ №1 готов на складе
Клиенту «ООО «ЭлектроМонтаж»» отправлено сообщение о готовности заказа №1
```

### 4. Клиент

Нажать Enter. На экране появится системное сообщение.

**Ожидаемый вывод:**
```text
Заказ №1 собран и готов к выдаче на складе. Срок хранения - 5 дн. Приходите за заказом.
```

### 5. Склад

Нажать Enter, выбрать задачу «Самовывоз: срок хранения, выдача заказа».

Ответить на вопросы:
- «Срок хранения заказа вышел?» — нет.
- «Клиент пришёл?» — да.

**Ожидаемый вывод:**
```text
Заказ выдан клиенту со склада
Заказ завершён
Складские остатки обновлены
```

### Итог

- Статус заказа: «заказ получен».
- Остаток партии 1: 0 шт.
- Остаток партии 2: 10 шт.

## Сравнение с процедурной реализацией

2. Запустить ООП-реализацию, как указано в текущем файле в разделе "Сборка и запуск"
3. Одинаковые шаги в обеих версиях
4. Ожидаемый вывод в консолях и итог должны совпадать

│       │   ├── DeliveryAddressRule.java  # Правило: для доставки указан адрес

│       │   ├── DeliveryConsole.java      # Консоль отдела доставки

│       │   └── JsonSerializable.java     # Интерфейс сохранения в JSON
